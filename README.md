# GreenWorth 신재생에너지 사업성 분석

육상풍력, 해상풍력, 태양광, ESS의 개발·건설부터 운영까지를 달력연도로 연결해 비교하는 프로젝트금융 사전 타당성 웹 애플리케이션입니다. 예시 엑셀에서는 입력 범주, 기간 구조와 검증용 결과만 참고했고 화면과 계산 코드는 새로 작성했습니다.

- 내용 수정 흐름: 브랜치에서 수정(프로토타입은 `prototypes/src/*.html` 수정 후 `npm run build:prototypes`) → PR → `master` 병합 → GitHub Actions "Deploy site"가 테스트 후 자동 배포(저장소 Actions 탭에서 진행 확인).
- 저장소가 공개이므로 사이트도 공개입니다. 민감 원본 파일은 `.gitignore`로 제외되어 사이트에 올라가지 않습니다.

## 실행

가장 간단한 방법은 `index.html`을 더블클릭해 바로 여는 것입니다. 별도 서버 없이도 모든 계산 기능이 동작합니다.

로컬 서버로 실행하려면 다음 명령을 사용합니다.

```bash
npm run serve
```

브라우저에서 `http://localhost:4173`을 엽니다. 외부 패키지 설치는 필요하지 않습니다.

## 입찰단가 프로토타입 (태양광 · 해상풍력 · BESS)

발전원별 경쟁입찰 조건으로 목표 수익(당사 이익 또는 목표 IRR)을 만족하는 적정 입찰가격을 역산하는 독립 페이지 3종입니다. 앱 상단의 "입찰단가 프로토타입" 링크 또는 `prototypes/index.html`에서 엽니다.

| 발전원 | 페이지 | 주요 기능 |
| --- | --- | --- |
| 태양광 | `prototypes/solar/index.html` | 국산·중국산 모듈 7종 비교와 탄소검증 등급 우대가격, 고정가격계약/기업PPA 조합, 상한가 진입 조건, 경쟁입찰 회차·대형 사업 사례, O&M 보증 발전시간 분석 |
| 해상풍력 | `prototypes/offshore-wind/index.html` | 터빈 6종 비교(터빈사 제공 순이용률·EPC 단가 직접 지정), 풍황 확률수준 P50·P75·P90 입력·비교, 목표 DSCR 부채 사이징, 공공주도형/일반 트랙·REC 가중치, 상한가 진입 조건, 선정 단지 18건 사례(보도·EIASS), 보증·LD(터빈사/EPC사)·준공지연 LD·하자보수 보증 |
| BESS(ESS) | `prototypes/bess/index.html` | ESS 중앙계약시장 적정 입찰단가 역산, 공급량·패널티, 선정평가 가격 환산, KCH 개발수수료, 입찰 사례(중앙계약시장 회차·선정 사업지) |

- 원본은 Claude Artifact에 게시한 HTML 조각인 `prototypes/src/{solar,offshore-wind,bess}.html`입니다. 원본을 고친 뒤 `npm run build:prototypes`로 사이트용 페이지(`prototypes/*/index.html`)와 발전원별 압축 파일(`prototypes/downloads/*.zip`)을 다시 만들어 함께 커밋합니다. 생성 페이지·압축 파일이 원본과 어긋나면 `npm test`가 실패합니다.
- 압축 파일에는 독립 페이지(`index.html`), 원본 조각(`artifact-source.html`), 안내문(`README.md`)이 들어 있으며, 압축을 풀고 `index.html`을 더블클릭하면 설치·인터넷 연결 없이 동작합니다.
- 사이트에서 열면 내보내기(CSV·JSON)는 브라우저 다운로드로 저장되고, 입력값·시나리오는 각자의 브라우저에만 저장됩니다.
- 프로토타입을 만들고 검증할 때 쓴 변환 파이프라인·브라우저 점검 스크립트·EIASS 조사 결과는 `prototypes/tools/`에 작업 기록으로 모아 두었습니다(사이트 빌드·테스트와 무관, 폴더 안내는 `prototypes/tools/README.md`). 설계 기준 문서는 `web-app-blueprint.md`, `result-tabs-design-spec.md`, 엑셀 회신 사양은 `excel-export-spec.md`(변환기 `ESS_엑셀변환.bat` · `ess-bidprice-xlsx.mjs`)입니다.
- `master`에 반영되면 GitHub Actions(`.github/workflows/pages.yml`)가 테스트 후 앱과 프로토타입, 압축 파일을 GitHub Pages로 배포합니다(저장소 설정 Pages의 Source = GitHub Actions).

## 모델 구조

### 발전량, 가격과 달력

- 기준연도, 사업 시작연도, 개발기간, 공사기간, COD 월과 운영기간으로 개발·건설·운영 현금흐름을 하나의 달력연도 축에 만듭니다.
- COD 이후 실제 운영일수와 윤년을 반영합니다. COD가 1월이 아니면 첫·마지막 운영연도를 부분연도로 일할 계산하고, COD가 1월이면 모든 운영연도는 전체연도로 계산합니다.
- 풍력과 태양광의 P75 순 이용률은 발전손실이 이미 반영된 순값입니다. 발전량에 별도 손실을 다시 차감하지 않습니다. ESS는 저장시간, 연간 사이클, 왕복효율과 소내소비율로 방전량을 계산합니다.
- ESS의 왕복효율(설비+배터리)은 변압기(154TR·22.9TR)·PCS 충방전·케이블 손실과 배터리 DC 왕복효율을 곱한 값이며, 소내소비율은 PCS 대기전력·배터리 냉각/BMS·LPMS 등 소내소비 부하가 충전전력량에서 차지하는 비율입니다. 방전량은 충전전력량에 왕복효율을 곱한 뒤 소내소비율만큼 추가로 차감해 계산합니다. 기본값은 260112_효성중공업 운전효율계산시트_KCH접수_V3.xlsx의 SDI·LGES·SKon 3사 제안값을 1년차 기준으로 평균한 값(왕복효율 89.5%, 소내소비율 3.3%)이며, 참조 시트에 나타난 배터리 DC 효율의 완만한 연차 하락(15년간 약 1~2%p)은 단순화를 위해 반영하지 않습니다.
- 판매가격 가정은 사업기간 동안 고정합니다. 시간에 따라 상승하는 항목은 건설 CAPEX의 물가상승과 OPEX의 물가상승뿐이며, 적용 기준연도도 각각 구분합니다.
- ESS는 운영 1년차부터 15년차까지 가동률 램프업 배수를 연차별로 각각 지정해 사이클 수에 곱합니다. 기본값은 1~2년차만 저조(95%/96%)하고 3년차 이후 정상(배수 1)이지만, 모든 연차를 자유롭게 편집할 수 있습니다. 운영기간이 15년보다 길면 16년차 이후는 항상 정상 가동률이 적용됩니다.
- ESS는 지정한 주기(기본 5년)마다 배터리를 증설(augmentation)해 열화된 용량 중 지정 비율을 회복하는 운영기간 중 재투자를 반영할 수 있습니다. 증설 CAPEX는 총사업비 11개 명세에 포함되지 않으며, 해당 연도의 배당가능현금을 먼저 사용하고 부족분은 자기자본 추가 투입으로 처리합니다. 증설 금액은 감가상각 기준연수만큼 별도 트랜치로 상각합니다. 마지막 운영연도에는 증설하지 않습니다.
- ESS의 배터리·PCS LTSA 항목은 지정 연차 이후 다른 계약단가(배율)를 적용할 수 있어, 제조사 워런티 종료 후 정비 단가가 상승하는 구간을 반영합니다.

### 총투자비와 금융

- 직접 CAPEX를 개발 비중과 공사기간 집행곡선에 따라 배분하고 건설비 물가상승, 예비비, 금융부대비용, 건설이자와 DSRA를 합산합니다.
- 건설이자(IDC)는 각 연도 기초 대출잔액과 그해 신규 인출액의 절반에 금리를 적용합니다. 금융부대비용, 건설이자와 DSRA가 다시 조달액에 영향을 주므로 총투자비는 허용오차 안에서 반복 계산합니다.
- 선순위대출은 거치기간 후 원리금균등 방식으로 상환하고 주민참여채권은 만기일시상환합니다. 만기 또는 운영종료 시 남은 원금은 해당 연도의 벌룬 상환액으로 명시합니다.
- DSRA는 고정 운영비가 아니라 예정 부채상환액에 DSRA 개월 수를 곱해 산정하는 회수 가능한 준비금입니다. 모델 종료 시 남은 DSRA는 자기자본 현금흐름으로 회수합니다.

### 세금과 배당

- 법인세와 지방소득세는 예시 파일의 역사적 가정을 합친 누진세율 프리셋으로 계산합니다. 현재 프리셋의 구간별 세율 9.9%, 20.9%, 23.1%는 2026년 현행 세법이나 세무자문이 아니며, 실제 투자 전 최신 세율과 적용 요건을 별도로 실사해야 합니다.
- 과세소득은 EBITDA에서 금융이자를 차감해 이자절세효과를 반영하고, 정액법 감가상각을 차감한 뒤 이월결손금(NOL)을 사용해 계산합니다. 감가상각은 COD와 실제 달력일수에 따라 일할하고, 이월결손금은 프리셋 기간 안에서 발생연도별로 사용합니다.
- 연간 DSCR은 해당 연도 CFADS를 해당 연도 부채상환액으로 나눈 값이고, 누적 DSCR은 누적 CFADS를 누적 부채상환액으로 나눈 값입니다. 두 기준을 모두 통과한 가용현금만 배당 검토 대상이 됩니다.
- 배당가능이익과 가용현금 중 작은 금액에서 법정준비금을 적립한 뒤 배당합니다. 기준을 통과하지 못한 현금은 유보현금으로 남기고, 법정준비금과 유보현금은 모델 종료 시 회수합니다. 투자자 배당세는 법인세와 분리해 투자자 세후 현금흐름에만 반영합니다.

### 수익성 지표

- P-IRR은 법인세 후, 금융 원리금 상환 전 프로젝트 현금흐름의 내부수익률입니다.
- E-IRR은 법인세 후 실제 자기자본 납입과 회수액을 사용하되 투자자 배당세를 차감하기 전의 자기자본 내부수익률입니다.
- 투자자 세후 E-IRR은 E-IRR과 같은 자기자본 현금흐름에서 투자자 배당세를 차감한 내부수익률입니다.
- NPV는 법인세 후 프로젝트 현금흐름을 기술별 프리셋 WACC로 할인한 현재가치입니다.
- P-PBP는 누적 법인세 후 프로젝트 현금흐름이 처음 0 이상이 되는 시점이며, 전환 연도 안에서는 현금흐름 비율로 보간합니다.

### 총사업비 11개 명세와 조달 대사

총사업비는 기자재, 토목, 전기, 선로·계통, 운송·설치, 간접비, 토지, 예비비, 건설이자, 금융부대비용, DSRA의 11개 명세로 표시합니다. 11개 명세 합계인 총사업비와 자기자본, 선순위대출, 주민참여채권의 조달합계를 각각 총투자비와 대사하며 차이가 있으면 계산 오류로 봅니다. DSRA는 11개 명세에 포함되지만 소비되는 공사비가 아니라 종료 시 회수할 수 있는 준비금입니다.

## 모델 경계

현재 모델은 사전 타당성 검토를 위한 달력연도 모델입니다. P50/P90 선택기, 월별·분기별 발전과 가격 곡선, VAT, 자산군별 감가상각, 대출상환액 맞춤 설계(sculpting), 리파이낸싱은 구현하지 않았습니다. 실제 금융약정, 세무신고 또는 투자심의에는 더 세분화한 현금흐름, 계약별 조건과 최신 기술·세무·법률·금융 실사가 필요합니다.

본 결과는 투자 의사결정 전 사전 검토를 위한 간이 추정치입니다. 실제 사업에는 기술·세무·법률·금융 실사와 독립된 재무모델 검증이 필요합니다.
