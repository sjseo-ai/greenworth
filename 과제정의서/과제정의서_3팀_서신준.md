# AX 실습 과제정의서 (초안)

KCH그룹 AX 워크숍 | 이노핏파트너스 · 작성일 2026-08-26

## 1. 과제 개요

| 구분 | 내용 |
| --- | --- |
| 작성자 / 소속 / 직급 | 서신준 / 인프라사업2 본부 / 매니저 |
| 그룹 | 프로젝트 재무·사업성 분석 시스템 |
| 과제명 | 재무모델 기반 사업성 분석 앱 (IRR·NPV·배당 분석 + B/S·I/S·CF + 매크로 Sensitivity 분석) |
| 한줄 요약 | 재무모델 파일을 업로드하는 대신, 매출·비용 성장률·자본구조·매크로 변수(금리·환율·물가상승률)·배당정책 등 **핵심 변수만 입력**하면 AI가 B/S·I/S·CF 재무모델을 자동 생성하고 IRR·NPV·배당 등 핵심 투자지표를 산출하며, 매크로 변수 조합에 따른 sensitivity 분석까지 자동 수행하는 웹앱(What-if 시뮬레이터). |
| 왜 AI인가 (한 줄) | 소수의 입력 변수만으로 프로젝트 특성에 맞는 재무모델 구조(B/S·I/S·CF 연결관계)를 스스로 구성해야 하고, 다수의 매크로 변수 조합에 따른 민감도 결과를 판단·요약하는 작업은 단순 수식 반복만으로는 확장하기 어렵고 맥락 이해가 필요하기 때문 |
| 업무 빈도 | 프로젝트 검토 시 비정기(건별 수시, 월 1~2건 수준) |
| 주 사용자 | ☑ 본인 전용 ☐ 팀 단위 ☑ 부서 전체 ☐ 외부 포함 |

### 시스템 유형

| 선택 | 유형 | 예 |
| --- | --- | --- |
| ☐ | AI 챗봇 / 사내 Q&A | 규정 챗봇, 과거 데이터 질의봇 |
| ☑ | 업무 자동화 파이프라인 | 핵심 변수 입력 → 재무모델 자동 생성 → 지표 계산 → 보고서 생성 |
| ☑ | 문서 자동 생성 | 사업성 분석 보고서, 재무제표(B/S·I/S·CF) 자동 정리 |
| ☐ | RAG 문서 검색·분석 | 정보지 아카이브에서 조항·사례 즉시 검색 |
| ☑ | AI 연동 대시보드 | 투자지표·Sensitivity 결과 현황판 |
| ☑ | 웹앱 / 내부 운영 툴 | 핵심 변수 입력 → 재무모델 자동 생성 및 분석 결과 조회 |
| ☐ | 시스템간 자동 연동 | 메일 수신 → AI 분류 → 알림 발송 |
| ☐ | 음성·영상 처리 | 회의록 자동 작성·요약 |

## 2. 현재 방식 (As-Is)

| 구분 | 내용 |
| --- | --- |
| 업무 빈도 | 프로젝트 검토 시 비정기(월 1~2건) |
| 1회 소요 시간 | 반나절 ~ 1일 (엑셀 수작업) |
| 담당 인원 | 1명 (본인, 필요 시 재무팀 협업) |
| 최종 결과물 | 사업성 검토 보고서(IRR/NPV 요약, B/S·I/S·CF, Sensitivity 표) |

### 업무 프로세스 (단계별로 구체적으로)

| 단계 | 하는 일 | 사용 도구 |
| --- | --- | --- |
| 1 | 프로젝트 재무모델(엑셀) 수집 및 가정값 확인 | 수기 검토 |
| 2 | B/S·I/S·CF 항목 정리 및 수식 검증 | 엑셀 수식 확인 |
| 3 | IRR·NPV·배당 등 투자지표 계산 | 엑셀 함수 |
| 4 | 금리·환율·물가상승률 등 매크로 변수 변경 시나리오별 반복 재계산 | 엑셀 매크로/수기 반복 |
| 5 | Sensitivity 분석 표·그래프 작성 | 엑셀 데이터 테이블·차트 |
| 6 | 보고서 정리 및 검토 | 워드/파워포인트 |

> **병목 지점:** 4~5단계(매크로 변수 조합별 반복 재계산 및 Sensitivity 표 작성) — 변수 조합이 많아질수록 수작업 반복 계산 부담이 크게 늘어납니다.

## 3. 만들 것 (To-Be)

### 입력 → 처리 → 출력 흐름

| 구분 | 내용 |
| --- | --- |
| 입력 | 재무모델 파일이 아닌 **핵심 변수**: 매출·비용 성장률, CAPEX/투자 규모, 운영기간, 자본구조(부채비율·조달금리), 매크로 변수(금리·환율·물가상승률), 배당정책 가정, 할인율 등 |
| 처리 (AI) | 입력 변수 검증(누락·이상값 체크 및 업계 표준치 제안) → 입력 변수만으로 B/S·I/S·CF 재무모델 자동 생성(연도별 추정재무제표) → IRR·NPV·배당 등 투자지표 자동 산출 → 매크로 변수 조합별 Sensitivity 분석 자동 수행(모델 반복 재생성·민감도 표·그래프 생성) → 계산 결과 이상치·가정 오류 자동 플래그 |
| 출력 | 사업성 분석 결과 웹페이지/리포트(입력 변수 요약 + IRR·NPV·배당 요약 + 생성된 B/S·I/S·CF + Sensitivity 분석 표·그래프), 변수 재입력 시 즉시 재계산되는 What-if 반복 사용, 필요 시 PDF 리포트 자동 회신 |

| AI가 하는 것 | 사람이 하는 것 |
| --- | --- |
| 1. 입력 변수 검증 및 부족한 값 업계 표준치 제안 | 1. 핵심 변수 값 입력·정의 |
| 2. 입력 변수 기반 B/S·I/S·CF 재무모델 자동 생성 | 2. 매크로 변수 범위·시나리오 설정 |
| 3. IRR·NPV·배당 등 투자지표 자동 계산 | 3. 결과 검토 후 변수 재조정(What-if 반복) |
| 4. 매크로 변수(금리·환율·물가상승률 등) 조합별 Sensitivity 분석 자동 생성 | 4. 최종 투자 판단 및 결과 승인 |
| 5. 계산 결과 이상치·가정 오류 자동 플래그 | |

## 4. 성공 기준 (3단계)

| 단계 | 기준 (측정 가능하게) |
| --- | --- |
| 최소 성공: 핵심 흐름이 한 번 작동 | 입력한 변수 세트로부터 B/S·I/S·CF 재무모델이 자동 생성되고 IRR·NPV·배당 지표가 한 번 산출됨 |
| 목표 성공: 반복 사용 가능한 형태 | 변수를 바꿔 입력할 때마다 재무모델·투자지표가 즉시 재계산되고, 매크로 변수 조합별 Sensitivity 분석까지 반복 실행 가능한 형태로 자동 수행됨 |
| 이상적 성공: 팀이 함께 쓰는 형태 | 여러 변수 시나리오(프로젝트)를 저장·비교 분석할 수 있고, 부서 전체가 실사용하며 앱으로 확장됨 |

## 7. 예상 구현 알고리즘 (미리보기)

이 과제를 실제로 구현할 경우의 작동 단계와 시스템 구조를 간단히 보여드립니다. 실습 진행 상황에 따라 조정될 수 있습니다.

| 단계 | 작동 내용 |
| --- | --- |
| 1 | 변수 입력: 사용자가 재무모델 파일 대신 핵심 변수(매출·비용 성장률, CAPEX/투자 규모, 자본구조, 매크로 변수, 배당정책 등)를 웹 UI에 입력 |
| 2 | 입력값 검증: 필수 변수 누락·범위 이상 여부 자동 체크, 부족한 값은 업계 표준치·추정치 제안 |
| 3 | 재무모델 생성: 입력 변수만으로 B/S·I/S·CF 추정재무제표를 연도별로 처음부터 자동 구성 |
| 4 | 지표 계산: 생성된 재무제표 기반 IRR·NPV·배당수익률 등 핵심 투자지표 자동 산출 |
| 5 | Sensitivity 분석: 매크로 변수(금리·환율·물가상승률 등) 조합별로 재무모델을 반복 재생성·재계산(매크로 기반), 민감도 표·그래프 자동 생성 |
| 6 | 이상치 검증: 생성된 재무제표의 논리적 정합성(B/S-I/S-CF 연결관계 등) 자동 점검, 오차·이상치 플래그 |
| 7 | 결과 통합: B/S·I/S·CF + 투자지표 + Sensitivity 결과를 웹페이지에 통합 정리, 변수를 바꾸면 즉시 재계산되는 What-if 반복 사용 |
| 8 | 검토·회신: 담당자가 결과를 검토·승인한 뒤 부서에 공유, 필요 시 PDF 리포트로 자동 회신 |

### 서비스 프로세스 흐름도 (사용자 여정)

시스템 내부 구조가 아닌, 사용자 관점에서 입력부터 결과 회신까지의 전체 흐름을 정리한 다이어그램이다.

```
┌──────────────────────────────┐
```

## 8. 부속 도구 — ESS 단가산정 모델 (엑셀)

본 과제의 ESS 사업을 대상으로, 목표 IRR에 맞춰 KCH가 받을 단가를 역산하는 실무용 엑셀 도구를 별도로 제작했다(`ESS_단가산정모델.xlsx`, 과제정의서 폴더).

### 목적과 IRR 기준

KCH가 ESS 발전원 개발자로서 수취하는 4개 수수료성 수익 — **부지 임대료, 사전개발비, 공동접속료, 운영수익** — 의 단가를, KCH 자체 투자수익률(개발비용 대비 수수료 수익 기준 IRR)이 목표치에 도달하도록 역산한다. 이는 기존 사업성모델 앱이 계산하는 **ESS 프로젝트 SPC(투자자) IRR과는 별개의 지표**이며, 4개 수익원은 KCH 입장에서는 수익이고 프로젝트 SPC 입장에서는 비용이 된다.

### 구조 (4개 시트)

| 시트 | 내용 |
| --- | --- |
| 읽어보기 | 모델 구조, 목표값 찾기(Goal Seek) 사용법 안내 |
| 입력 | 사업 규모(설비용량·저장용량·개발/공사/운영기간), KCH 비용(용지비·개발비·관리비), 4개 수익원별 기준단가·상승률, 목표 IRR, 공통 가격배율 |
| 현금흐름 | 연차별 KCH 현금흐름을 수식으로 자동 계산(`=IRR()`, `=NPV()` 네이티브 함수) |
| 요약 | 목표 IRR 대비 달성 IRR, 가격배율 반영 후 4개 수익원 실제 단가, 총수익·총비용·NPV |

### 핵심 메커니즘 — 공통 가격배율 + 목표값 찾기(Goal Seek)

4개 수익원의 기준단가에 동일하게 곱해지는 **공통 가격배율** 셀 하나를 두어, Excel 목표값 찾기(데이터 → 가상 분석 → 목표값 찾기)로 "달성 IRR = 목표 IRR"이 되도록 이 배율 하나만 풀면 4개 단가가 함께 역산된다. 개별 단가를 직접 지정하고 싶으면 배율을 1.00으로 둔 채 기준단가 칸을 직접 수정해도 된다.

### 시나리오 변동 — 민감도표

입력 시트 하단에 **가격배율(세로) × 설비용량(가로) → 달성 IRR** 조합을 보여주는 Excel 네이티브 Data Table을 배치했다(Excel 데이터 표 기능상 입력 셀과 같은 시트에 있어야 하는 제약으로 입력 시트 안에 위치). 목표 IRR 이상을 달성하는 칸은 조건부 서식으로 초록색 표시된다.

> **참고:** 파일에 담긴 예시 입력값(50MW/200MWh 등)은 placeholder이며, 실제 사업 수치로 교체해 사용한다.
